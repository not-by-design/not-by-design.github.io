## Purpose of this directory
This directory holds one standalone file for developing and planning each content idea. The idea index is [CONTENT_BACKLOG.md](../CONTENT_BACKLOG.md); keep the one-line entry there and the detailed work here.

## Creating new files
Name each file `<id>.md`, using the numeric ID assigned in the backlog. Start the file with the ID and a working title, and link back to its backlog entry. For example, idea `[0]` uses `0.md`.
